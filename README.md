# Civitas

## About

Civitas is an application for exploring Brazilian electoral data in a simple and structured way.

Users will be able to explore elections, candidates, political parties, votes and electoral results, as well as compare data across different elections and locations.

## Problem

Brazilian electoral data is publicly available, but exploring, comparing and extracting useful information from large electoral datasets can be difficult and time-consuming.

## Goal

The goal of Civitas is to transform public electoral data into structured and searchable information, providing tools for queries, rankings, comparisons and historical analysis.
